# C++ 算法模板：求约数个数与约数之和

## 1. 题目背景与核心公式
**题目链接：** [AcWing 873. 约数之和 / 约数个数](https://www.acwing.com/problem/content/873/)

任何一个正整数 N，都可以通过**算术基本定理**（唯一分解定理），分解为多个质数的乘积形式：
**N = p1^a1 * p2^a2 * ... * pk^ak** *(注：其中 p1, p2...pk 是从小到大的质数因子，a1, a2...ak 是对应的指数)*

基于这个质因数分解的结果，我们可以推导出两个重要的公式：

* **约数个数公式：** (a1 + 1) * (a2 + 1) * ... * (ak + 1)
* **约数之和公式：** (p1^0 + p1^1 + ... + p1^a1) * (p2^0 + p2^1 + ... + p2^a2) * ... * (pk^0 + pk^1 + ... + pk^ak)

---

## 2. 代码实现

这段代码利用哈希表 `unordered_map` 巧妙地记录了每个质因数及其出现的次数（指数），然后分别实现了求约数个数和约数之和的逻辑。

```cpp
#include <iostream>
#include <algorithm>
#include <unordered_map>

using namespace std;
typedef long long ll;

const int mod = 1e9 + 7;

int main() {
    int n;
    cin >> n;
    
    // primes 用于存储质因数及其对应的指数
    // key: 质因数 (prime), value: 出现的次数/指数 (alpha)
    unordered_map<int, int> primes; 
    
    while (n--) {
        int x;
        cin >> x;

        // 分解质因数的核心模板
        for (int i = 2; i <= x / i; i++) {//若i为x的因数，则x/i也是x的因数，不妨设i<=x/i
            while (x % i == 0) {
                x /= i;
                primes[i]++;
            }
        }
        // 如果最后 x 还没被除尽，说明剩下的 x 本身就是一个大于 sqrt(原始x) 的质数
        if (x > 1) primes[x]++;
    }

    /* =======================================
       1. 求约数个数 (已注释)
    ll res = 1;
    for (auto prime : primes) {
        res = res * (prime.second + 1) % mod;
    }
    cout << res << endl;
    ======================================= */

    // 2. 求约数之和
    ll res = 1;
    for (auto prime : primes) {
        int p = prime.first, a = prime.second;
        ll t = 1;
        
        // 核心求和逻辑：计算 (p^0 + p^1 + ... + p^a)
        while (a--) {
            t = (t * p + 1) % mod;//很巧妙
        }
        res = res * t % mod;
    }
    
    cout << res << endl;
    
    return 0;
}
