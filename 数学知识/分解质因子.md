# 数论基础：分解质因数模板
对于一个正整数 n，我们不需要遍历到 n，只需遍历到“根号 n”,因为一个数 n 最多只能有一个大于“根号 n”的质因子。

题目链接：https://www.acwing.com/problem/content/869/
### 1. 核心逻辑

1. **从小到大试除**：从 2 开始遍历。如果 `n % i == 0`，说明 `i` 是 `n` 的一个质因子。（因为如果 `i` 是合数，它一定早就被比它小的质数除干净了）。
2. **除干净并计数**：用一个 `while` 循环把 `n` 里面所有的 `i` 都除掉，同时记录这个质因子出现的次数 `s`。
3. **处理漏网之鱼**：循环结束后，如果 `n > 1`，说明剩下的这个 `n` 就是那个唯一大于原本“根号 n”的质因子，直接输出一次即可。

### 2. 模板

```cpp
#include <iostream>

using namespace std;

// 分解质因数函数
void divide(int n) {
    // 优化：只需要遍历到 i <= n / i 
    for (int i = 2; i <= n / i; i++) {
        if (n % i == 0) { // i 一定是质数
            int s = 0; // 记录质因子 i 的个数            
            // 把 n 里面所有的 i 都除干净
            while (n % i == 0) {
                n /= i;
                s++;
            }
            // 输出当前质因子及其个数
            cout << i << " " << s << endl;
        }
    }
    
    // 如果最后 n 仍然大于 1，说明剩下的 n 是一个大于原根号 n 的质因子
    if (n > 1) {
        cout << n << " " << 1 << endl;
    }
    
    // 极其重要：每个数的质因数输出完毕后，额外输出一个空行隔开
    cout << endl;
}

int main() {
    int n;
    cin >> n; 
    while (n--) {
        int x;
        cin >> x;
        divide(x);
    }
    
    return 0;
}
