# 图的存储：Vector 邻接表与出边排序模板

在使用 vector 模拟邻接表存图时，我们经常遇到题目要求“如果有多条边，按目标节点编号从小到大遍历”的附加条件。这种情况下，vector 结合自定义比较函数 cmp 和 std::sort 是最优雅的解决方案。

### 1. 核心逻辑

1. **二维 Vector 存图**：`vector<vector<edge>> v(n)` 动态开辟了 n 个节点的邻接表。
2. **自定义排序**：定义 cmp 函数，按目标节点编号（`to`）升序排列。
3. **批量排序**：在所有边读取完毕后，统一遍历每个节点的 vector 并进行排序。

### 2. 标准 C++ 模板

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

// 定义边结构体
struct edge {
    int to;     // 终点
    int weight; // 边权
};

// 自定义比较函数：按目标节点编号升序排序
bool cmp(edge a, edge b) {
    return a.to < b.to;
}

int main() {
    int n, e; // n 为节点数，e 为边数
    cin >> n >> e;
    
    // 初始化二维 vector 存图，包含 n 个一维 vector
    vector<vector<edge>> v(n);

    // 读入所有边
    for (int i = 0; i < e; i++) {
        int a, b, c; // 起点 a，终点 b，权重 c
        cin >> a >> b >> c;

        edge tmp;
        tmp.to = b;
        tmp.weight = c;
        v[a].push_back(tmp); // 将边存入起点 a 的邻接表中
    }

    // 核心操作：对每个节点的所有出边进行排序
    for (int i = 0; i < n; i++) {
        sort(v[i].begin(), v[i].end(), cmp);
    }
    
    // 遍历输出图的结构
    for (int i = 0; i < n; i++) {
        // 只输出有出边的节点
        if (v[i].size() != 0) {
            cout << i << ":";
            for (int j = 0; j < v[i].size(); j++) {
                // 格式化输出：(起点, 终点, 权重)
                cout << "(" << i << "," << v[i][j].to << "," << v[i][j].weight << ")";
            }
            cout << endl;
        }
    }

    return 0;
}
