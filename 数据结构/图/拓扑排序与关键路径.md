# 图论进阶：拓扑排序与 AOE 网 (关键路径) 模板

AOE 网（Activity On Edge Network）主要用于求工程的“最短完成时间”和“关键路径”。它的核心前置技能是拓扑排序。本模板采用了基于 `queue` 的最优拓扑排序写法，时间复杂度为 O(N + E)。

### 1. 核心逻辑

1. **队列拓扑排序**：利用队列存储入度为 0 的节点，避免 O(N^2) 的暴力扫描。
2. **正向计算 ve (最早发生时间)**：在拓扑排序出队时，顺便计算 `ve[next] = max(ve[next], ve[curr] + weight)`。
3. **逆向计算 vl (最迟发生时间)**：逆着拓扑序列遍历，计算 `vl[u] = min(vl[u], vl[v] - weight)`。
4. **寻找关键路径**：遍历所有边，若起点最早发生时间等于终点最迟发生时间减去边权（即 `ve[u] == vl[v] - weight`），则该边为关键活动。
