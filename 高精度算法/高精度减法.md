# 高精度减法
> **题目链接：** [AcWing 792. 高精度减法](https://www.acwing.com/problem/content/794/)

## 1. 算法思路
高精度减法相比加法稍微复杂一点，主要涉及两个核心逻辑：
1.  **大小比较**：减法必须保证是用“大数”减“小数”。
    - 如果 $A \ge B$，直接算 $A - B$。
    - 如果 $A < B$，算 $-(B - A)$。所以需要一个 `cmp` 函数来判断大小。
2.  **借位处理**：
    - 如果当前位不够减 ($t < 0$)，需要向高位借 1 (即当前位 $+10$)。
    - 如果够减，则不需要借位。

## 2. 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>
#include <vector>

using namespace std;

// 判断是否 A >= B
bool cmp(vector<int> &A, vector<int> &B) {
    // 1. 先比长度，长度大的肯定大
    if (A.size() != B.size()) return A.size() > B.size();
    
    // 2. 长度相等，从高位（数组末尾）开始一位一位比
    for (int i = A.size() - 1; i >= 0; i--) {
        if (A[i] != B[i]) return A[i] > B[i];
    }
    
    // 3. 完全相等
    return true;
}

// 核心减法函数 (前提：A >= B)
vector<int> sub(vector<int> &A, vector<int> &B) {
    vector<int> res;
    int t = 0; // t 表示借位
    
    for (int i = 0; i < A.size(); i++) {
        t = A[i] - t; // 当前位 A[i] 减去之前的借位
        if (i < B.size()) t -= B[i]; // 如果 B 这一位有数，再减去 B[i]
        res.push_back((t + 10) % 10);//巧妙的处理
        
        // 更新借位：如果 t < 0 说明不够减，借过位了，下一次要减 1
        if (t < 0) t = 1;
        else t = 0;
    }
    
    // 去除前导零
    // 例如 100 - 99 = 001，需要去掉前面的两个 0，变成 1
    while (res.size() > 1 && res.back() == 0) res.pop_back();
    
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b;
    cin >> a >> b;
    
    vector<int> A, B;
    // 倒序存储
    for (int i = a.size() - 1; i >= 0; i--) A.push_back(a[i] - '0');
    for (int i = b.size() - 1; i >= 0; i--) B.push_back(b[i] - '0');

    // 分情况讨论
    if (cmp(A, B)) {
        auto C = sub(A, B);
        for (int i = C.size() - 1; i >= 0; i--) cout << C[i];
    } else {
        // A < B，输出负号，然后算 B - A
        cout << "-";
        auto C = sub(B, A);
        for (int i = C.size() - 1; i >= 0; i--) cout << C[i];
    }
    
    return 0;
}
