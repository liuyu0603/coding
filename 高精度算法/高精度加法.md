# 高精度加法
> **题目链接：** [AcWing 793. 高精度加法](https://www.acwing.com/problem/content/793/)

## 1. 算法思路
- **核心问题**：C++ 中 `long long` 最大只能存 $10^{18}$ 左右的数，而题目要求的数字长度可达 $10^6$。
- **解决方案**：使用 `vector<int>` 数组来模拟人工竖式加法。
- **存储技巧**：**倒序存储**。
    - 将字符串的最后一位（个位）存入数组的 `0` 号下标，更普遍来说，加减乘除都是数组的低位来存数字的高位
    - **原因**：加法产生进位时，需要在高位补充数字。对于数组来说，在末尾 `push_back` 是 $O(1)$ 的操作，而在数组头部插入是 $O(N)$ 的操作。

## 2. 代码实现

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

// 高精度加法核心函数
vector<int> add(vector<int> &A, vector<int> &B) {
    vector<int> res;
    int t = 0; // t 用于存储进位，同时暂存当前位的和
    // i < A.size() || i < B.size() 这个写法可以处理两数长度不一致的情况
    for (int i = 0; i < A.size() || i < B.size(); i++) {
        if (i < A.size()) t += A[i];
        if (i < B.size()) t += B[i];
        
        res.push_back(t % 10); 
        t /= 10;               
    }
    
    // 处理最高位的进位
    if (t) res.push_back(t);
    
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b;
    cin >> a >> b;
    
    vector<int> A, B;
    // 倒序处理：字符串转数字数组
    for (int i = a.size() - 1; i >= 0; i--) A.push_back(a[i] - '0');
    for (int i = b.size() - 1; i >= 0; i--) B.push_back(b[i] - '0');

    auto C = add(A, B);
    
    // 倒序输出结果（因为计算时是倒着存的，输出要反过来）
    for (int i = C.size() - 1; i >= 0; i--) cout << C[i];
    
    return 0;
}
