# 题目：数的范围
> **题目链接：** [AcWing 791. 数的范围](https://www.acwing.com/problem/content/791/)

## 1. 题目思路
这是一个经典的整数二分查找问题。题目要求在一个排序数组中，查找某个数 $x$ 的起始位置和结束位置。
- 找**起始位置**（左边界）：性质是 $\ge x$，我们要找的是满足这个性质的第一个数。
- 找**结束位置**（右边界）：性质是 $\le x$，我们要找的是满足这个性质的最后一个数。

## 2. 代码实现

```cpp
#include<iostream>
using namespace std;

const int N=1e6+10;
int q[N];
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n,m;
    cin>>n>>m;
    for (int i=0;i<n;i++)cin>>q[i];

    while(m--) {
        int x;
        cin>>x;
        int l=0,r=n-1;
        while(l<r) {
            int mid=(l+r)/2;//向下取整，[l,mid]故mid向下取整
            if (q[mid]>=x)r=mid;//找第一个大于等于x，看mid的位置，第一个大于等于x的mid位置
            else l=mid+1;
        }
        if (q[l]!=x) {
            cout<<"-1 -1"<<endl;
            continue;
        }
        else {
            cout<<l<<" ";
            int l=0,r=n-1;
            while(l<r) {
                int mid=(l+r+1)/2;//向上取整
                if (q[mid]<=x)l=mid;//找第一个小于等于x的所以这里是小于等于号，选择答案所在的区间进行二分
                else r=mid-1;
            }
            cout<<r<<endl;
        }
    }
    return 0;
}
```

## 3. 学习笔记与思考

### 核心难点：边界处理与死循环
整数二分最容易写出死循环，关键在于 `mid` 的取整方式要和区间的更新方式匹配：

1.  **当区间被划分为 `[l, mid]` 和 `[mid+1, r]` 时：**
    * 更新方式是 `r = mid` 或 `l = mid + 1`。
    * 此时 `mid` 使用默认的 **向下取整**：`int mid = (l + r) / 2;`。
    * *原因*：如果剩下两个数 `[l, r]`（即 `r = l + 1`），向下取整 `mid = l`。如果判断成立走 `r = mid`，区间变成 `[l, l]`，循环结束。

2.  **当区间被划分为 `[l, mid-1]` 和 `[mid, r]` 时：**
    * 更新方式是 `l = mid` 或 `r = mid - 1`。
    * 此时 `mid` 必须 **向上取整**：`int mid = (l + r + 1) / 2;`。
    * *原因*：如果剩下两个数 `[l, r]`（即 `r = l + 1`），如果不加1，`mid = l`。如果走 `l = mid` 分支，区间依旧是 `[l, r]`，导致 **死循环**。
    * **口诀**：一旦出现 `l = mid`，计算 mid 时就要 `+1`。

### 补充
- **浮点数二分**：比整数二分简单，因为不需要处理整除边界问题，不需要 `+1`，只需要设定一个精度阈值（如 `r - l > 1e-8`）即可。
- **对二分的进一步思考**：满足某种性质，即大于这个或者小于这个数，有单调递增或者单调递减的性质，一般是最大值或者最小值，可以考虑二分！！
