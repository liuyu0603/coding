# 算法基础：位运算与离散化
**位运算的常用操作**（如 `lowbit`）以及**基于离散化和前缀和的区间和问题**。

---

## 1. 位运算基础常识

这些是处理二进制数据时非常实用的技巧：

* **查看第 `k` 位**：`n >> k & 1`
    * 作用：将数字 `n` 的二进制表示向右移动 `k` 位，然后与 `1` 进行按位与操作，即可得到原来第 `k` 位的值（`0` 或 `1`）。`k=0` 时即不移动，查看最低位。
* **获取最低位的 1 (`lowbit` 操作)**：`x & -x`
    * 作用：返回数字 `x` 的二进制表示中，从右边开始数的第一个 `1` 以及它后面的 `0` 构成的数值。例如，若 `x = 101000`（二进制），则 `lowbit(x) = 1000`（二进制）。
    * 代码实现：通常单独定义一个函数 `int lowbit(int x) { return x & -x; }`。
    * 常见应用：用于树状数组，或者用来统计一个二进制数字里有多少个 `1`（每次减去 `lowbit(x)` 直到 `x` 为 0）。

---

## 2. 经典应用：区间和 (离散化)

当我们需要对一些跨度非常大（例如下标范围在 $-10^9$ 到 $10^9$）、但实际用到非常稀疏的坐标进行修改和区间求和时，就需要用到**离散化**。它将庞大且稀疏的坐标映射到紧凑的、从 `1` 开始的连续下标中，随后配合**前缀和**即可快速求解。

* **题目来源**：[AcWing 804. 区间和](https://www.acwing.com/problem/content/description/804/)

### C++ 实现代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

const int N = 3e6 + 10;
typedef pair<int, int> pii;

int n, m;
int a[N], s[N];
vector<int> alls;
vector<pii> add, query;

// 二分查找，求出原坐标 x 离散化后的新坐标（保证从 1 开始，方便求前缀和）
int find(int x) {
    int l = 0, r = alls.size() - 1;
    while (l < r) {
        int mid = (l + r) >> 1; // 相当于 (l+r)/2，位运算加速
        if (alls[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return r + 1; // 返回 1-based 的索引
}

int main() {
    // 优化 I/O 读取速度
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;

    // 1. 读取插入操作
    for (int i = 0; i < n; i++) {
        int x, c;
        cin >> x >> c;
        add.push_back({x, c});
        alls.push_back(x); // 将需要操作的坐标加入待离散化数组
    }

    // 2. 读取查询操作
    for (int i = 0; i < m; i++) {
        int l, r;
        cin >> l >> r;
        query.push_back({l, r});
        alls.push_back(l); // 将查询的左右端点坐标也加入待离散化数组
        alls.push_back(r);
    }

    // 3. 对坐标数组进行离散化的核心：排序 + 去重
    sort(alls.begin(), alls.end());
    alls.erase(unique(alls.begin(), alls.end()), alls.end());

    // 4. 处理插入，将值累加到离散化后的对应位置
    for (auto item : add) {
        int x = find(item.first);
        a[x] += item.second;
    }

    // 5. 预处理前缀和数组
    for (int i = 1; i <= alls.size(); i++) {
        s[i] = s[i - 1] + a[i];
    }

    // 6. 处理查询，利用前缀和 O(1) 求解区间和
    for (auto item : query) {
        int l = find(item.first);
        int r = find(item.second);
        cout << s[r] - s[l - 1] << "\n";
    }

    return 0;
}
