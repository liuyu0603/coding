### 题目链接：https://www.luogu.com.cn/problem/P8612

---
### 分析：其实动态规划就是一个层层拨开的过程，对于本题，想要去刻画（x,y）处一共有多少种走法，首先，至少需要x,y两维，同时，由于题目对个数有限制，很显然也需要一维；
### 分析：最后，由于这是一个单调递增的序列，因此需要额外记录当前最后一位数字是多少.
### 那么，对于d[x][y][cnt][val]，其中(x,y)表示位置，cnt表示已经有多少个物品，val表示目前最大的价值;
### d[x][y][cnt][val]怎么得来呢？它可以是上一个d[x-1][y][cnt][val],也可以是d[x][y-1][cnt][val]得来，再加上对于当前x，y位置上选不选，共计四种情况.

---
### 代码如下
```cpp
#include<iostream>
#include<algorithm>

using namespace std;

int mod=1e9+7;
const int N=55;
int f[N][N][15][15];
int w[N][N];

int main(){
    int n,m,k;
    cin>>n>>m>>k;
    for(int i=1;i<=n;i++)
        for(int j=1;j<=m;j++)
        {cin>>w[i][j];
//由于要刻画（1，1）处不拿，因此所有价值都要+1
            w[i][j]++;
        }
//（1，1）处若是拿物品
    f[1][1][1][w[1][1]]=1;
//若是不拿
    f[1][1][0][0]=1;

    for(int i=1;i<=n;i++)
    for(int j=1;j<=m;j++)
    {
        if(i==1&&j==1)continue;
        for(int u=0;u<=k;u++)
//全部都不拿价值就是0，因此要从0开始遍历
            for(int v=0;v<=13;v++){
                int&val=f[i][j][u][v];
//若是（i,j）处不拿
                val=(val+f[i-1][j][u][v]+f[i][j-1][u][v])%mod;
//若是拿，则此时的价值要刚好等于这个位置的价值
                if(u>0&&w[i][j]==v){
//在拿之前，价值可以从0~v
                    for(int c=0;c<v;c++){
                        val=(val+f[i-1][j][u-1][c])%mod;
                        val=(val+f[i][j-1][u-1][c])%mod;
                    }
                }
            }
        }
//最后拿了k件物品，总计价值可以是0~13；
    int res=0;
    for(int i=0;i<=13;i++)res=(res+f[n][m][k][i])%mod;
    cout<<res;
    return 0;
}
