# C++ 算法模板：动态规划 - 01背包问题

## 1. DP 核心分析框架 (状态表示与状态计算)

动态规划 (DP) 问题通常可以从两个角度进行降维打击：**状态表示** 和 **状态计算**。

### 状态表示：f(i, j)
* **集合：** 只从前 i 个物品中选，且总体积小于等于 j 的所有选法方案。
* **属性：** 通常是最大值 (Max)、最小值 (Min) 或者数量。在 01 背包中，属性是**价值的最大值**。

### 状态计算：状态转移方程
当我们计算 f(i, j) 时，可以将集合划分为两个互不相交的子集：
1.  **不选第 i 个物品：** 最大价值等价于从前 i-1 个物品中选，且体积不超过 j。即 `f(i-1, j)`。
2.  **选第 i 个物品：** 既然一定要选第 i 个物品，那我们就先把第 i 个物品的空间 `v[i]` 腾出来，再看前 i-1 个物品能装出的最大价值，最后加上第 i 个物品的价值 `w[i]`。即 `f(i-1, j - v[i]) + w[i]`。

综合两者取最大值，得到核心状态转移方程：
**f(i, j) = max(f(i-1, j), f(i-1, j - v[i]) + w[i])**

## 2. 二维 DP 代码实现 (基础版)

这是最符合直觉的原始版本代码，时间复杂度 O(N*V)，空间复杂度 O(N*V)。

```cpp
// 动态规划：01背包问题 (每件物品最多用一次)
#include <iostream>
#include <algorithm>

using namespace std;
const int N = 1010;

int v[N], w[N]; // v 存体积，w 存价值
int f[N][N];    // 二维状态表

int main() {
    int n, m;
    cin >> n >> m; // n 为物品数量，m 为背包容量
    
    // 读入每个物品的体积和价值
    for (int i = 1; i <= n; i++) cin >> v[i] >> w[i];

    // 双重循环填表
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 默认情况：不选第 i 个物品
            f[i][j] = f[i-1][j]; 
            // 只有当背包剩余容量 j 能够装下第 i 个物品时，才考虑更新最大值
            if (j >= v[i]) {
                f[i][j] = max(f[i][j], f[i-1][j - v[i]] + w[i]);
            }
        }
    }
    
    // 输出最优解
    cout << f[n][m] << endl;

    return 0;
}

```
## 可进一步优化为一维
```cpp
#include<iostream>
#include<algorithm>

using namespace std;
const int N=1010;

int v[N],w[N];
int f[N];

int main() {
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=n;i++)cin>>v[i]>>w[i];

    for (int i=1;i<=n;i++) {
    //为什么接下来要倒序遍历呢？
    //因为j-v[i]比v[i]小，滚动数组本质是用下一轮的值覆盖上一轮的值，所以正序遍历会覆盖掉左上角的旧值，只有倒序遍历才能正确拿到左上角的旧值！
        for (int j=m;j>=v[i];j--) {//下界是v[i],因为如果j比v[i]都小，那就不用优化了
            f[j]=max(f[j],f[j-v[i]]+w[i]);
        }
    }
    cout<<f[m];
    return 0;
}
