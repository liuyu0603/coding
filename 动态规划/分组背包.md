### 1. 什么是“分组背包”？

顾名思义，物品被划分成了 $n$ 个**组**。
**核心铁律是：对于每一个组，最多只能从中挑选 1 件物品**（也可以一件都不挑）。

### 2. 变量

这段代码用二维数组来存储分组信息，非常直观：

* `n`：总共有多少个组。
* `m`：背包的最大容量。
* `s[i]`：第 $i$ 个组里面，总共有多少件物品。
* `v[i][j]` 和 `w[i][j]`：代表第 $i$ 个组里的第 $j$ 件物品的**体积**和**价值**。
* `f[j]`：我们熟悉的一维滚动数组，表示容量为 $j$ 时能获得的最大价值。

---

### 3. 为什么是这样的三层循环？

这段代码最精华、也是最容易让人迷惑的地方，就是它的三层循环顺序。我们把它单独摘出来看：

```cpp
for(int i = 1; i <= n; i++)           // 第一层：遍历每一个组
    for(int j = m; j >= 0; j--)       // 第二层：背包容量倒序遍历
        for(int k = 0; k < s[i]; k++) // 第三层：遍历当前组内的每一件物品
            if(v[i][k] <= j)
                f[j] = max(f[j], f[j - v[i][k]] + w[i][k]);
