### 分析：f[i][j]：字符串 a 的前 $i$ 个字符，和字符串 b 的前 $j$ 个字符，它们的最长公共子序列的长度。
### 状态转移方程怎么推导:对于a[i]与b[j]，若它俩不同则最大值在f[i-1][j]与f[i][j-1]中，若它俩相同，则f[i][j]与f[i-1][j-1]+1中

#### 代码如下
```cpp
#include<iostream>
#include<algorithm>

using namespace std;
const int N=1010;
int f[N][N];
char a[N],b[N];

int main(){
    int n,m;
    cin>>n>>m;
    
    for(int i=1;i<=n;i++)cin>>a[i];
    for(int i=1;i<=m;i++)cin>>b[i];
    
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            f[i][j]=max(f[i-1][j],f[i][j-1]);
            if(a[i]==b[j])f[i][j]=max(f[i][j],f[i-1][j-1]+1);
        }
    }
    
    cout<<f[n][m];
    return 0; 
}
