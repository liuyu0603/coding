# 基础算法笔记：前缀和与差分 (Prefix Sum & Difference Array)

**一维前缀和** 与 **一维差分** 

## 1. 一维前缀和 (1D Prefix Sum)

**核心思想**：
预处理出一个数组 `s`，其中 `s[i]` 表示原数组前 `i` 个数的总和。
通过公式 `s[r] - s[l-1]`，可以在 O(1) 的时间复杂度内快速求出原数组在区间 `[l, r]` 内的和。
```cpp
#include <iostream>
#include <vector>

using namespace std;

const int N = 1e6 + 10;
int a[N], s[N]; // a为原数组，s为前缀和数组

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    // 读取数据 (建议从下标 1 开始，方便处理边界)
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    // 核心计算：初始化前缀和数组
    // s[i] = s[i-1] + a[i]
    for (int i = 1; i <= n; i++) {
        s[i] = s[i - 1] + a[i];
    }

    // 处理询问
    while (m--) {
        int l, r;
        cin >> l >> r;
        // 区间查询公式：s[r] - s[l-1]
        cout << s[r] - s[l - 1] << endl;
    }

    return 0;
}
