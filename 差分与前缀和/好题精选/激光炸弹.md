# 算法笔记：激光炸弹 (二维前缀和典型应用)

### 1. 题目链接：https://www.acwing.com/file_system/file/content/whole/index/content/3650/
采用了 **二维前缀和 (2D Prefix Sum)** 技术，将查询区域价值的时间复杂度从 $O(R^2)$ 降低到了 $O(1)$。

---

### 2. 代码如下

```cpp

#include <iostream>
#include<algorithm>

using namespace std;
const int N=5010;
//动态变化目标点的区域，实际上我们并不一定需要完整的遍历5000*5000个结点
int n,m;
int s[N][N];//一开始先存的是每个结点的价值，再用前缀和，省空间

int main() {
    int cnt,R;
    cin>>cnt>>R;
    R=min(5001,R);

    n=m=R;
    while (cnt--) {
        int x,y,w;
        cin>>x>>y>>w;
        //由于前缀和下标必须从1开始，因此在这里所有的横纵左边都加1
        x++;y++;
        //动态扩大地图的大小
        n=max(n,x),m=max(m,y);
        s[x][y]+=w;
    }
    //获取前缀和，即从（1，1）到（i,j）这一块区域的前缀和
    for (int i=1;i<=n;i++)
        for (int j=1;j<=m;j++)
            s[i][j]+=s[i-1][j]+s[i][j-1]-s[i-1][j-1];

    int res=0;
    //计算以（i,j）为右下角，R为边长的区域的价值最大值
    for (int i=R;i<=n;i++)
        for (int j=R;j<=m;j++)
            res=max(res,s[i][j]-s[i-R][j]-s[i][j-R]+s[i-R][j-R]);
    cout<<res<<endl;
    return 0;
}
