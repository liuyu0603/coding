# P8685 [蓝桥杯 2019 省 A] 外卖店优先级

## 题目描述

“饱了么”外卖系统中维护着 $N$ 家外卖店，编号 $1$ ~ $N$。每家外卖店都有一个优先级，初始时（$0$ 时刻）优先级都为 $0$。

每经过 $1$ 个时间单位，如果外卖店没有订单，则优先级会减少 $1$，最低减到 $0$；而如果外卖店有订单，则优先级不减反加，每有一单优先级加 $2$。

如果某家外卖店某时刻优先级大于 $5$，则会被系统加入优先缓存中；如果优先级小于等于 $3$，则会被清除出优先缓存。

给定 $T$ 时刻以内的 $M$ 条订单信息，请你计算 $T$ 时刻时有多少外卖店在优先缓存中。

## 输入格式

第一行包含 $3$ 个整数 $N$ 、 $M$ 和 $T$。

以下 $M$ 行每行包含两个整数 $ts$ 和 $id$，表示 $ts$ 时刻编号 $id$ 的外卖店收到一个订单。

## 输出格式

输出一个整数代表答案。

## 输入输出样例 #1

### 输入 #1

```
2 6 6
1 1
5 2
3 1
6 2
2 1
6 2
```

### 输出 #1

```
1
```

## 说明/提示

**样例解释**

$6$ 时刻时，$1$ 号店优先级降到 $3$，被移除出优先缓存；$2$ 号店优先级升到 $6$，加入优先缓存。所以有 $1$ 家店（$2$ 号店）在优先缓存中。

### 分析：诸如此类情况较为复杂的题，可以先在记事本上思考好对应每一步该怎么写，对应每一步可以怎么做，简短的代码实现，再去敲整体的代码，有条不紊

对于本题，第一个点就是对于成对出现的数据，t，id，可以用pair<int,int>来存，非常方便；
其次就是思考内在的逻辑联系，按照时间顺序排好序的话，一个时间可以给多个店铺提交订单，我们并不是每一条订单优先级减少一次，而是每过一秒减少一次；
实际上，对于我本次该减多少，实际上只要减去我上次是啥时候接的订单就行，类似pre数组
具体实现如下：
```cpp
#include<iostream>
#include<algorithm>

using namespace std;

const int N=1e5+10;

pair<int,int>orders[N];
//第一个表示时间，第二个表示编号
int n,m,T;
//是否是已经在优先缓存中
bool st[N];
//记录上次出现的时间，优先级
int last[N],pri[N];
int main(){
    cin>>n>>m>>T;
    
    for(int i=1;i<=m;i++){
        cin>>orders[i].first>>orders[i].second;
    }
    
    sort(orders+1,orders+m+1);
//按时间去处理
    for(int i=1;i<=m;i++){
        int t=orders[i].first;
        int id=orders[i].second;
//假如对于当前的店铺id，此时的时间和上一次接单的时间不同（为了避免同一时间连续接了几条单子的情况）
//也就是特殊情况的处理
        if(t!=last[id]){
//为什么是t-1呢？假如上一次接单是1s，现在是5s，现在要接单了啊！！所以得从4开始算起
            int gap=t-1-last[id];
            if(gap>0){
                pri[id]=max(0,pri[id]-gap);
//有减少的时候，看看有没有可能特别小了呢？
                if(pri[id]<=3)st[id]=false;
            } 
        }
//对于一般情况的话
        pri[id]+=2;
        if(pri[id]>5)st[id]=true;
        last[id]=t;
    }
//规定时间为T，每一个店铺最后一次接单到规定时间还有一段间隙
    for(int i=1;i<=N;i++){
        if(last[i]<T){
            int gap=T-last[i];
            pri[i]=max(0,pri[i]-gap);
            if(pri[i]<=3)st[i]=false;
        }
    }

    int res=0;
    for(int i=1;i<=n;i++){
        if(st[i])res++;
    }
    cout<<res;
    return 0;
}
