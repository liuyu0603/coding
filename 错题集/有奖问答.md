##  有奖问答

小蓝正在参与一个现场问答的节目。活动中一共有 $30$ 道题目，每题只有答对和答错两种情况，每答对一题得 $10$ 分，答错一题分数归零。

小蓝可以在任意时刻结束答题并获得目前分数对应的奖项，之后不能再答任何题目。最高奖项需要 $100$ 分，所以到达 $100$ 分时小蓝会直接停止答题。请注意小蓝也可能在不到 $100$ 分时停止答题 $^{[1]}$。

已知小蓝最终实际获得了 $70$ 分对应的奖项，请问小蓝所有可能的答题情况有多少种？

```cpp
#include <iostream>

using namespace std;

int main() {
    // dp[i][j] 表示答了 i 道题，当前分数为 j 的情况数
    // j 的范围是 0 到 10（分别代表 0分, 10分, 20分 ... 100分）
    long long dp[35][15] = {0};

    // 初始状态：0道题，0分，有 1 种情况
    dp[0][0] = 1;

    // 开始遍历 30 道题
    for (int i = 0; i < 30; i++) {
        for (int j = 0; j <= 9; j++) { 
            // 注意：j=10 (即100分) 时会自动停止，不再往下推导转移
            if (dp[i][j] > 0) {
                // 1. 下一题答错：分数归 0
                dp[i + 1][0] += dp[i][j];

                // 2. 下一题答对：分数加 10 (即索引 j + 1)
                dp[i + 1][j + 1] += dp[i][j];
            }
        }
    }

    // 统计所有达到 70 分的情况
    long long total_ans = 0;
    
    // 遍历第 1 题到第 30 题
    for (int i = 1; i <= 30; i++) {
        // 只要在第 i 题时分数达到了 70 分（对应的索引是 7）
        // 小蓝就可以选择停止，所以把这些情况都累加起来
        total_ans += dp[i][7]; 
    }

    cout << total_ans << endl; // 输出结果：8335366

    return 0;
}
