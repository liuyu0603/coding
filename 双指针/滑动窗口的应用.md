# 双指针与滑动窗口 

滑动窗口是双指针算法的一种，主要用于解决数组或字符串中连续子区间的问题。它通过维护一个“窗口”（即两个指针构成的区间 `[left, right]`），在遍历过程中动态调整窗口的边界，从而将嵌套循环的 $O(N^2)$ 复杂度优化到 $O(N)$。

---

## 1. 经典应用：最长连续不重复子序列

### 题目描述
给定一个长度为 n 的整数序列，请找出最长的不包含重复的数的连续区间，输出它的长度。

### C++ 实现代码
```cpp
#include <iostream>
#include <algorithm>

using namespace std;

const int N = 1e6 + 10;
int a[N]; 
int s[N]; // 频率数组（哈希表），记录当前窗口内每个数字出现的次数

int main() {
    // 优化 I/O 读取速度
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    int res = 0;
    // i 为窗口右边界（主动扩展），j 为窗口左边界（被动收缩）
    for (int i = 0, j = 0; i < n; i++) {
        s[a[i]]++; // 将当前元素加入窗口，更新频率

        // 当窗口内出现重复元素时，左指针 j 开始收缩，直到重复元素被移出窗口
        while (s[a[i]] > 1) {
            s[a[j]]--; // 移出左边界元素
            j++;       // 左指针右移
        }
        
        // 此时窗口 [j, i] 内一定没有重复元素，更新最大长度
        res = max(res, i - j + 1);
    }
    
    cout << res << "\n";

    return 0;
}
```
